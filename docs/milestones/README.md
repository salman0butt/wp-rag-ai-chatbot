# Milestone Program

Every milestone uses the required lifecycle:

NOT STARTED -> DESIGN -> PLANNED -> IMPLEMENTING -> VERIFYING -> REVIEW -> COMPLETE

BLOCKED is used when an external stop condition prevents progress.

No milestone may be marked COMPLETE without acceptance criteria, required TDD/integration/E2E evidence, relevant security/accessibility/performance review, independent code review, fixes/re-review, fresh verification, documentation updates, and commit references.
